Background

The long way round

I started as a software engineer in India. Writing code, building systems, figuring out how enterprise software actually behaves when real people touch it.

That curiosity took me to Italy, then to London in 2005. Over the next two decades I worked inside some of the world's largest companies. Unilever, Mars, Shell, BP. The kind of transformations that touch hundreds of millions of consumers without any of them knowing it happened.

Programme governance, AI strategy, data platforms, digital marketplaces. I've shipped them all, usually across three continents at once, usually with a budget someone said was too small.

In 2024 I stepped back from corporate life. In 2025 I came back briefly to support the Magnum Ice Cream separation from Unilever, working on the technology side of the M&A programme. Then back to building. The gap I keep seeing: AI is genuinely useful, but almost nobody outside tech is getting the benefit of it. That's the problem I'm working on.

AI Patterns

AI in practice

Not as academic exercises. These are the actual patterns powering Miru, Intel and the rest — each one solving a real problem for a real user.

Retrieval-Augmented Generation
Ground the model in real data before generating — search first, generate second.
Intel fetches live web articles, financials and news before generating a brand report — so the output is accurate, not hallucinated. Miru searches your saved WhatsApp items to answer "what was that restaurant?" without touching an LLM until needed. Try RAG in action →
Intel Miru
Orchestration
Chain multiple AI steps and API calls into a single coherent response.
A single Miru WhatsApp message triggers: classify intent → select tool → call external API (trains, fuel, council, GP) → format a clean reply. Six steps, under two seconds, invisible to the user.
Miru Intel
Structured Extraction
Use an LLM to pull typed, schema-valid data from messy unstructured input.
Miru's school comms feature reads raw email HTML from Gmail and extracts structured events — title, date, action required — as JSON. The same pattern reads wine labels, product barcodes and bill photos from WhatsApp images.
Miru
Multi-Modal Input
Accept images, audio and text as inputs — not just typed prompts.
Miru accepts WhatsApp photos as first-class inputs: a barcode photo → ISBN lookup → book added to your library. A wine label → vintage, producer, grape, region saved to your notes. A bill photo → amount and due date extracted.
Miru
Persistent AI Memory
Give the model per-user context that survives across sessions — not just a conversation window.
Miru remembers your home postcode, children's school profiles, linked WhatsApp number and saved items — all persisted in Supabase. Every reply is personalised without the user repeating themselves.
Miru
Tool Use / Function Calling
Let the model decide which external function or API to call, and with what arguments.
Intel's research pipeline uses function calling to route between search, financial data, news and company registry APIs — the model decides what it still needs to know and keeps calling until the report is complete.
Intel Miru
Proactive AI Agent
Monitor external state and push relevant information to users without them asking.
Miru's 2026 local council elections feature runs a background agent that polls Democracy Club for new results, detects when a user's ward has declared, and pushes a WhatsApp alert automatically — the AI acts on a real-world trigger, not a user request. Live at miru.humanagency.co/elections.
