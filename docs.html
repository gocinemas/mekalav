Miru Agent APIs

Build with autonomous agents. Integrate any of our agents into your application with simple REST APIs.

Getting Started

The Miru API provides access to autonomous agents for train times, fuel prices, elections, expenses, and council services. All requests use JSON and HTTPS.

Base URL: https://api.miru.studio/v1

Authentication

Include your API key in the Authorization header:

curl -H "Authorization: Bearer YOUR_API_KEY" \ https://api.miru.studio/v1/train/departures

Get Your API Key

Sign up for a Miru Studio account and generate an API key in your dashboard.

Train Agent

Get real-time train departure times and journey planning.

GET

/train/departures

Get upcoming departures from a station

Parameters:

Name Type Description
station string 3-letter station code (e.g., KGX, LBG, LVT)
limit integer Number of results (default: 10, max: 50)
filter string Filter by destination station code

Example Request:

curl -H "Authorization: Bearer YOUR_API_KEY" \ "https://api.miru.studio/v1/train/departures?station=KGX&limit=5"

Response:

{ "station": "KGX", "trains": [ { "time": "14:32", "destination": "Cambridge", "platform": "7", "delay": null }, { "time": "14:47", "destination": "Peterborough", "platform": "3", "delay": "+2" } ] }

Fuel Agent

Find cheapest fuel prices near a location.

GET

/fuel/prices

Get nearby fuel prices

Parameters:

Name Type Description
postcode string UK postcode (e.g., SW1A1AA)
radius integer Search radius in miles (default: 5, max: 20)
fuel_type string petrol or diesel

Rate Limits

Free tier: 100 requests/day. Pro tier: 10,000/month. Custom limits available.
